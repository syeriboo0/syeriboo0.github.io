NutriPath: Health and Nutrition Tracking Web App

Team of 5. We built a Java web application that brings BMI, food logging, exercise tracking and goal progress together on one dashboard.

CourseSKJ3013 Advanced Java Programming
TeamTeam of 5
Session2025/2026
JavaServletsJSPMVCDAO patternMySQLApache TomcatBootstrap
SummaryPeople who want to manage their health usually juggle several apps: one for BMI, one for food and one for exercise. NutriPath combines them. Users log meals and workouts, the app calculates BMI and net calories automatically, and a progress page charts weight trends against personal goals.

Problem → solution

ProblemNutriPath feature
Health data spread across many toolsCentral dashboard with weight, height and BMI
Calorie maths is tedious and easy to get wrongDaily tracker that shows calories eaten minus calories burned automatically
People lose motivation over timeGoal setting with start and target dates, plus a line-graph progress review
Data must stay privateSeparate user and admin logins with session handling

View

Login, signup, dashboard, daily tracker, goals, profile and progress-review pages. They handle presentation only, with no business logic.

Controller

Servlets for login and logout, profile, goals, food and exercise logging, deletion, and progress summaries.

Model

Beans (User, DailyFood, DailyExercise, Goal) carry the data. DAO classes keep all database access in one place.

Runtime

Built in Eclipse, deployed on Apache Tomcat, with MySQL storage and a Bootstrap front end.

Testing

  • Functional testing checked that the servlet and JSP logic handles health data correctly, including BMI and net-calorie calculations.
  • UI testing checked navigation, session persistence and that the layout stays consistent across pages.

Limitations and next steps

  • Calories are entered by hand. An automated food database would improve accuracy.
  • A dedicated mobile app is planned as a future enhancement.

What I learned

  • How a clean MVC split with the DAO pattern keeps a Java web app maintainable as it grows.
  • Handling sessions and role-separated logins in a servlet application.
  • Writing proper documentation (architecture, ERD, testing) alongside the code.
