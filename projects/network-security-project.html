Internet Network Security Project: Lightweight IDS with Telegram Alerting

Team of 3. We built a small intrusion-detection setup that recognises four common network attacks and pushes real-time alerts to Telegram.

CourseNetwork Security
TeamTeam of 3
FormatGroup project + presentation

SummaryWe simulated four attacks from a Windows XP machine against a Kali Linux sensor: Ping of Death, ARP spoofing, SMTP banner probing and FTP brute force. A script watched the IDS alert log and forwarded each detection to Telegram.

Why Windows XP?

It's lightweight, easy to configure and well suited to a controlled lab where legacy behaviour is useful.

Why Kali Linux?

It's open source and customisable, with defensive tools (IDS, Wireshark, scripting) already built in.

Attacks covered and how we detected them

AttackWhat it isDetection signal
Ping of DeathDoS using oversized or malformed ICMP packets that can trigger buffer overflows. This is different from an ICMP flood, which relies on volume.ICMP payload size far above normal
ARP spoofingFake ARP replies link the attacker's MAC address to a legitimate IP (often the gateway), redirecting traffic through the attacker.One IP suddenly mapped to a different MAC; gratuitous ARP replies
SMTP banner probingReconnaissance: connect to the mail port and read the server banner to fingerprint the software and version.Short TCP sessions to port 25 with no mail sent
FTP brute forceRepeatedly guessing username and password pairs against port 21 until one works.Many failed USER/PASS attempts from one source in a short time

Alerting

A script watches the alert log file and calls the Telegram Bot API whenever a new detection appears, so the responder gets the alert on their phone. Wireshark was used alongside the IDS to inspect and confirm each attack at packet level.

What I learned

  • Different attacks leave very different footprints: size (PoD), identity mismatch (ARP), behaviour (banner probing) and frequency (brute force).
  • Explaining how an attack works made writing the detection logic much easier.
  • I practised splitting a security build across a team and presenting it clearly.
