Maghrib Prayer Reminder: An Agentic AI Workflow

Team of 3. We built an autonomous agent on the Make automation platform that works out Maghrib time for each user's location and sends them a Telegram reminder, with no human involved.

CourseSKJ3183 Artificial Intelligence
TeamTeam of 3
PlatformMake (formerly Integromat)
MakeAgentic AIREST APIGoogle SheetsTelegram BotAutomationEthics by design
SummaryDuring Ramadan, Maghrib marks both the prayer time and the time to break the fast, so accurate timing really matters. Our agent runs on a schedule, reads each user's location, fetches the live Maghrib time from a prayer-time API, decides whether it's time, and sends one respectful Telegram message.

What makes it "agentic"

CharacteristicHow our agent does it
AutonomyRuns continuously on a scheduled trigger, with no manual step
PerceptionFetches real-time Maghrib times from an external prayer-time API
Context awarenessUses each user's location from Google Sheets to make location-specific decisions
ReasoningRule-based logic compares the current time with that location's Maghrib time
ActionSends the Telegram reminder only when the conditions are met

Ethics and privacy by design

  • Consent: users opt in by submitting their own Telegram chat ID.
  • Data minimisation: we store only the data the agent needs (chat ID and location).
  • No spam: exactly one message at Maghrib time.
  • Cultural sensitivity: message wording was written to respect religious values.

What I learned

  • How to build a working agent from a trigger, perception, a decision and an action using low-code tools.
  • How to connect external services (REST API, Google Sheets, Telegram) and pass data between them reliably.
  • Privacy principles like consent and data minimisation belong in the design from the start, not added at the end. This links directly to my information security studies.
