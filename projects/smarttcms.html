SmartTCMS: Smart Test Case Management System

Team project. We built a web application that helps small development teams create, run, track and report on test cases, designed with role-based security from the start.

CourseSKJ2083 Software Engineering
TeamTeam project
Duration14 weeks · Agile
SubmittedJune 2025

SummaryStudent teams often track testing in spreadsheets and chat messages. SmartTCMS gives them one place to manage projects, test cases, executions, history and reports, with separate permissions for Admin, Tester, Developer and Manager roles.

Core features

Authentication & roles

Secure login and registration with role-based access for Admin, Tester, Developer and Manager.

Projects

Create projects and drill into each one (for example, a "Mobile Banking" project) to see its test cases.

Test cases

Create, edit, run and delete test cases with module, priority, preconditions, steps and expected results.

Review & reports

Developers comment on test cases, every change is logged to history, and summary reports can be generated.

Security design

  • Test cases, bug reports and user logs are classified as confidential.
  • Role-based authorisation: admins manage users and the system, while testers and developers get only what their role needs.
  • Audit logging of user activity through the history table.
  • A defined incident-reporting procedure for suspicious activity.

Tools and process

We used the Agile model across the 14 weeks, Visual Studio Code for development, Git and GitHub for version control, Postman for API testing, MySQL Workbench for database design and UML for system design.

What I learned

  • Turning requirements into an architecture, a data model and UI designs before writing code.
  • Applying security principles (classification, least privilege, audit trails) to a real system design.
  • Working in a team with Git, Agile sprints and shared documentation.
